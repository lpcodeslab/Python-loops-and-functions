# Python-loops-and-functions
Python programs demonstrating While Loop, For Loop, Control Statements, and Functions through a Number Guessing Game, Multiplication Table Generator, and BMI Calculator.

## Description
This repository contains Python programs based on While Loops, For Loops, and Functions.

## Programs Included

### 1. Number Guessing Game
- Uses a While Loop.
- Generates a random number between 1 and 10.
- Allows the user 3 attempts.
- Uses `break`, `continue`, and `else`.

### 2. Multiplication Table Generator
- Uses a For Loop.
- Takes a number from the user.
- Prints the multiplication table from 1 to 10.

### 3. BMI Calculator
- Calculates Body Mass Index (BMI).
- Takes weight in kilograms and height in meters.
- Uses the formula:

  BMI = Weight / (Height × Height)

## Concepts Used
- While Loop
- For Loop
- If-Else Statements
- Break and Continue
- Functions (`def`)
- User Input
- Basic Mathematical Operations
